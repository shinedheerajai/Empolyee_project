# Project Description
A comprehensive data analysis project focused on extracting meaningful insights 
from HR datasets using SQL in Postgre SQL. This project explores employee 
distribution, salary patterns, department-wise analysis, and workforce trends 
to support data-driven HR decisions.


# Tasks Performed
.Conducted data investigations and quality assurance checks for the HR data.  
.Analyze employee counts, averages, distributions across various dimensions 
like department, age, education etc.
.Identify the most common job roles in each department.  
.Calculate the average job satisfaction for each education level.  
.Determine the average age for employees with different levels of job.  
.Calculate the attrition rate for each age band.  
.Identify the departments with the highest and lowest average job satisfaction.  
.Analyse the age band with the highest attrition rate among employees with 
a specific education level.  
.Analyse the education level with the highest average job satisfaction among 
employees who travel frequently.  
.Identify the age band with the highest average job satisfaction among married employees.
